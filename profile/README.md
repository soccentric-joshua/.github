# Joshua

Open-source embedded Linux platform for **Texas Instruments Sitara**, from [SoCcentric](https://github.com/Soccentric).
MIT licensed.

| Repository | Purpose |
|---|---|
| [Joshua-OS](https://github.com/soccentric-joshua/Joshua-OS) | Yocto/kas image build |
| [meta-joshua](https://github.com/soccentric-joshua/meta-joshua) | Yocto layer for the board |
| [Joshua-HAL](https://github.com/soccentric-joshua/Joshua-HAL) | Hardware abstraction layer (C++17) |
| [Joshua-Client](https://github.com/soccentric-joshua/Joshua-Client) | gRPC client (C++17) |
| [Joshua-Server](https://github.com/soccentric-joshua/Joshua-Server) | Test server (Drogon, C++) |
| [Joshua-Configuration](https://github.com/soccentric-joshua/Joshua-Configuration) | WebConfig on-device configuration |
| [Joshua-Dashboard](https://github.com/soccentric-joshua/Joshua-Dashboard) | HTML5 dashboard |
| [Joshua-PySDK](https://github.com/soccentric-joshua/Joshua-PySDK) | Python SDK |
| [Joshua-Instrumentation](https://github.com/soccentric-joshua/Joshua-Instrumentation) | On-device management and observability |
| [Joshua-HQ](https://github.com/soccentric-joshua/Joshua-HQ) | Fleet management |
| [Joshua-Hardware](https://github.com/soccentric-joshua/Joshua-Hardware) | Hardware documentation |

Contributions go to the `develop` branch. See the shared [contributing guide](https://github.com/soccentric-joshua/.github/blob/main/CONTRIBUTING.md).
